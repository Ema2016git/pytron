# Pytron — Asistente de Inteligencia Artificial

Una interfaz de chat moderna y elegante que conecta con los mejores modelos de IA del mundo: GPT-4o, Claude, Gemini y DeepSeek. Crea tus propios tipos de IA personalizados.

## Características

- **Multi-proveedor**: Conecta con OpenAI, Anthropic, Google y DeepSeek
- **IAs personalizadas**: Crea tus propios tipos de IA con personalidad, instrucciones y modelo preferido
- **8 plantillas incluidas**: Programador, Escritor, Tutor, Chef, Fitness, Analista, Traductor, Creativo
- **Streaming en tiempo real**: Las respuestas se generan palabra por palabra
- **Markdown completo**: Renderizado de código, tablas, listas, enlaces y más
- **Syntax highlighting**: Resaltado de código en 180+ lenguajes
- **Historial de chats**: Tus conversaciones se guardan localmente
- **Selector de modelos**: Cambia entre modelos con un clic
- **Diseño responsive**: Funciona en desktop y móvil

## Cómo usar

1. Abre `index.html` en tu navegador
2. Haz clic en **Configuración** para ingresar tus API keys
3. Selecciona el modelo en la barra superior
4. ¡Empieza a chatear!

## Crear IAs personalizadas

1. En la barra lateral, haz clic en el **+** junto a "Mis IAs"
2. Elige un emoji, color, nombre y escribe las instrucciones
3. Opcionalmente usa una plantilla como base
4. Haz clic en tu IA para activarla — todas las conversaciones usarán esa personalidad
5. Edita o elimina tus IAs en cualquier momento
